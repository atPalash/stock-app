# 📊 Query commands guide

Use these commands to run and manage your queries:

**/query run** – Run a query, AI will help you!
**/query subscribe** – Subscribe to a query
**/query subscribe_ls** – List subscribed query
**/query unsubscribe** – Unsubscribe to a query
**/query help** – Show help for query commands

Supported subscription intervals: 5m, 15m, 30m, 1h, 1d, 1wk

Supported indicators and periods:
- SMA: periods 5, 10, 20, 50, 100, 200
- EMA: periods 5, 10, 20, 50, 100, 200
- ATR: periods 10, 14
- VWAP: periods 10
- RVOL: periods 10, 20

Tip: Share your intent in plain language and I'll try to convert it into a runnable query. 🚀
